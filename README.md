# Healthcare Analytics Dashboard

## Project Overview
This project analyzes healthcare data using Power BI to understand patient admissions, department referrals, patient demographics, and satisfaction trends.

## Tools Used
- Power BI
- Power Query
- DAX
- Python (for data cleaning)

## Key Insights
- Total patient count
- Patient distribution by gender and age group
- Department referral analysis
- Patient admission trends
- Patient satisfaction analysis

## Dashboard Features
- KPI cards for key metrics
- Interactive filters
- Charts for patient demographics and department analysis
- Cleaned dataset for better analysis

## Dataset
The project uses healthcare data containing patient details, admission dates, department referrals, and satisfaction information.
